# PHP Doctor Appointment System 🏥

A web-based platform designed to simplify hospital management and streamline the doctor-patient appointment booking process. Built using PHP, MySQL, HTML, CSS, and JavaScript.

---

## 🚀 Features

* **Patient Panel:** 
  * Register and manage patient accounts.
  * Search available doctors by specialization.
  * Book, view, and cancel appointments.

* **Doctor Panel:**
  * Manage daily schedules and appointment slots.
  * View patient booking details and appointment status.

* **Admin Panel:**
  * Comprehensive dashboard to manage doctors, patients, and appointment schedules.
  * Approve or cancel bookings.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Bootstrap
* **Backend:** PHP
* **Database:** MySQL
* **Environment:** XAMPP Server
